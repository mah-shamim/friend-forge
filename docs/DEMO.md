# Demo story

A friend wants to improve English for interviews and organize a busy week.

1. Add three goals.
2. Add today's tasks.
3. Record new vocabulary.
4. Use AI Chat: "Act as an interviewer. Ask me one question at a time and correct my grammar after each answer."
5. Ask: "Create a 30-minute English practice plan for tomorrow using my goals."
6. Save the useful plan as a private note.

All AI calls go from PHP to the Ollama container on the private Docker network.
